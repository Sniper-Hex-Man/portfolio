# 🏢 Enterprise Building & Real Estate Management System (BMS)
> **نظام إدارة المباني والعقارات وإدارة وكلاء العقار والمستأجرين**

---

## 📌 Arabic Overview | نظرة عامة
تطوير نظام **BMS** المتقدم كحل مؤسسي متكامل لإدارة المحافظ العقارية والمباني السكنية والتجارية. يمنح النظام ملاك العقارات رؤية مركزية شاملة لأصولهم العقارية مع منح الوكلاء صلاحيات محددة لإدارة المباني المسندة إليهم ومتابعة الإيجارات والتحصيل والتحصيلات المالية بكتل تنبيهية شفافة.

### ✨ المميزات والخصائص الرئيسية:
- **إدارة المحافظ العقارية الشاملة**: إضافة وتصنيف المباني والشقق والوحدات مع تتبع كامل لبيانات السكن والتعاقدات.
- **نظام وكلاء العقار والصلاحيات الأدق (RBAC)**: تعيين وكيل لكل مبنى بصلاحيات محددة لإدارة الإيجارات والطلبات والتوليد التلقائي للطلبات المعلقة للمالك.
- **متابعة التحصيل والإيجارات**: تنبيهات دورية ذكية للإيجارات المستحقة والمتأخرة، وإرسال إشعارات تلقائية عبر الواتساب/SMS.
- **التقارير المالية والتشغيلية**: تتبع الدخل والمنصرفات، عقود الصيانة، أجور الصيانة والوكلاء، والمستحقات المتبقية.
- **لوحة مراقبة وإشعارات آنية للمالك**: تتبع حركة الاستلام والعمليات الجارية في اللحظة نفسها.

## 🌐 English Overview
Engineered an enterprise-class **Building Management System (BMS)** designed for real estate investors and property owners to manage multi-tenant residential and commercial complexes. Features multi-tier role-based access control, automated lease tracking, and financial analytics.

### 🚀 Key Highlights & Capabilities:
- **Comprehensive Asset Management**: Structure buildings, storeys, apartments, and tenant contracts with real-time occupancy monitoring.
- **Granular Multi-agent RBAC**: Delegate management of specific properties to property agents with workflow approvals.
- **Automated Rent Collection & Alerts**: Payment due tracking with integrated WhatsApp/SMS notifications for overdue balances.
- **Financial & Maintenance Telemetry**: Granular reports covering cash flow, maintenance tickets, agent commissions, and net yield.
- **Owner Control Tower**: Real-time activity feed monitoring all agent collection actions and property updates.

## 🛠️ Technical Stack | التقنيات المستخدمة
- **Backend Architecture**: Laravel & Livewire (Full-stack SPA Reactive Architecture)
- **Database Engine**: MySQL with optimized query relational index
- **Real-time Capabilities**: Pusher / WebSockets Notifications
- **UI Framework**: Modern Dashboard Theme with Dynamic Dark/Light Mode support
