# 🔍 Lost & Found Community Mobile Platform
> **تطبيق وموقع المفقودات التفاعلي لربط العاثرين بالأصحاب**

---

## 📌 Arabic Overview | نظرة عامة
تطوير منصة وتطبيق مجتمعي مبتكر يهدف إلى حل مشكلة الأغراض المفقودة والموجودات بطريقة تقنية عصرية. يعتمد التطبيق على التواصل المباشر ونشر البلاغات المدعومة بالصور والموقع الجغرافي والوصف لتسهيل استرجاع الممتلكات المفقودة وتجسير التواصل بين العاثر والمالك.

### ✨ المميزات والخصائص الرئيسية:
- **نشر وتصنيف البلاغات (Lost & Found Posts)**: إمكانية رفع بلاغ عن غرض مفقود أو مقتنى تم العثور عليه مع وصف دقيق وتصوير.
- **التواصل الآمن الفوري**: نظام محادثات أو تواصل مباشر لترتيب استلام المفقودات مع حماية الخصوصية.
- **الفلترة بالبحث والموقع**: تصفح البلاغات حسب المنطقة، الفئة (إلكترونيات، وثائق، ممتلكات شخصية)، أو التاريخ.
- **تطبيق محمول وتأطير عالي (Flutter & Laravel)**: أداء فائق وتطبيق سلس عبر كافة الأجهزة.
- **تطوير لوحة تحكم إشرافية (Web Dashboard)**: متابعة الممتلكات وتدقيق البلاغات والمحتوى لضمان سلامة الاستخدام.

## 🌐 English Overview
Developed a **Community Lost & Found Platform** designed to solve the common issue of misplaced belongings by connecting finders with owners through a secure mobile application. Users can publish geolocation-tagged posts with detailed descriptions and images.

### 🚀 Key Highlights & Capabilities:
- **Structured Lost/Found Dispatch**: Easily post lost items or reported found belongings with photos, locations, and descriptions.
- **Secure Communication**: Direct in-app messaging enabling finders and owners to coordinate returns safely.
- **Advanced Filtering & Geolocated Search**: Filter reports by category (electronics, documents, personal items), proximity, or date.
- **Cross-Platform Mobile App**: Built with Flutter and backed by a robust Laravel API framework.
- **Content Moderation Dashboard**: Web back-office for managing postings, flagging spam, and overseeing system statistics.

## 🛠️ Technical Stack | التقنيات المستخدمة
- **Mobile Frontend**: Flutter (Dart)
- **Backend Architecture**: Laravel (PHP) REST APIs
- **Database Engine**: MySQL
- **Cloud & Storage**: S3-compatible File Storage / Local Secure Storage
