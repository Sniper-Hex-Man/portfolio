# ✂️ Darz - Smart Tailoring Ecosystem
> **نظام وتطبيق "درز" لإدارة محلات الخياطة وتسهيل تفصيل الأثواب في السوق السعودي**

---

## 📌 Arabic Overview | نظرة عامة
تطوير نظام **درز (Darz)** المتخصص في تقديم حلول رقمية مبتكرة لقطاع الخياطين في السوق السعودي. جاء النظام نتيجة دراسة ميدانية لاحتياجات أصحاب محلات الخياطة، حيث يوفر تجربة سلسة لإدارة المقاسات، اختيار الأقمشة، وتتبع تنفيذ الطلبات من الجوال واللوحات الإدارية.

### ✨ المميزات والخصائص الرئيسية:
- **إدارة مقاسات التفصيل الذكية**: حفظ السجلات الرقمية لمقاسات العملاء وتفضيلات الخياطة بدقة وتفادي الأخطاء.
- **عرض الأقمشة والتصاميم**: كتاالوج رقمي يسهّل اختيارات العميل ويربطها بالطلب المخزني.
- **تطبيق محمول وتوافق تام (Flutter UI)**: واجهة مرنة تعمل على الجوالات والتابلت داخل المحل لخدمة العملاء.
- **لوحة تحكم إدارية (Laravel Dashboard)**: متابعة أداء الفروع، الطلبات الجديدة، والإحصائيات المالية.
- **قابليّة التوسع والتطوير**: هيكل تقني مهيأ للربط مع الأنظمة الحكومية والزكاة والضريبة والفلترة التلقائية.

## 🌐 English Overview
Developed **Darz**, a specialized digital solution engineered for the traditional and modern tailoring industry in Saudi Arabia. Built based on direct field research with tailors, the system streamlines custom measurement tracking, fabric selection, and order processing.

### 🚀 Key Highlights & Capabilities:
- **Digital Measurement Storage**: Cloud repository for detailed customer measurement profiles and styling preferences.
- **Interactive Fabric & Model Catalog**: Digital showcase connecting customer selections directly to workshop inventory.
- **Responsive Mobile & Tablet App**: Built with Flutter for smooth on-the-spot customer service inside retail outlets.
- **Central Admin Portal**: Laravel backend powering branch performance analytics, order lifecycle, and financial tracking.
- **Extensible Integration Pipeline**: Architecture designed for enterprise expansion and electronic invoicing compliance.

## 🛠️ Technical Stack | التقنيات المستخدمة
- **Mobile Frontend**: Flutter Framework (Dart)
- **Backend Infrastructure**: Laravel REST APIs
- **Database Engine**: MySQL
