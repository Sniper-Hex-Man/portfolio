# 🎡 Peako - Kids Playground & Parental Peace of Mind Mobile Ecosystem
> **تطبيق Peako لإدارة ملاعب الأطفال والمتابعة المباشرة لسلامة الأبناء**

---

## 📌 Arabic Overview | نظرة عامة
تطوير تطبيق محمول مبتكر يمثل حلقة وصل بين أولياء الأمور ومراكز الترفيه وملاعب الأطفال. يمنح التطبيق الوالدين تجربة مريحة وآمنة لمتابعة أبنائهم داخل المنتزهات والملاعب عبر تكنولوجيا البث المباشر للشاشات وإشعارات الحركة والتنبيهات، إضافة إلى إدارة رصيد بطاقات الألعاب رقمياً.

### ✨ المميزات والخصائص الرئيسية:
- **إدارة المحفظة وبطاقات الألعاب (Digital Game Pass)**: إمكانية شحن رصيد الألعاب فورياً عبر التطبيق وتجنب الانتظار في طوابير الاستقبال.
- **المتابعة المباشرة عبر الكاميرات (Live Camera Feed)**: مشاهدة الأبناء داخل مناطق اللعب والترفيه بشكل آمن ولحظي عبر التطبيق.
- **تنبيهات الدخول والخروج (Entry/Exit Smart Alerts)**: إشعار فوري لولي الأمر لحظة دخول الطفل للعبة أو انتقاله لمنطقة أخرى.
- **واجهة مستخدم عصرية وسريعة (Flutter Native Experience)**: تجربة مستخدم سلسة تناسب مختلف الأجهزة الذكية.

## 🌐 English Overview
Developed **Peako**, a smart mobile solution for parents visiting kids' entertainment centers and amusement parks. The mobile application combines digital play pass management with real-time video surveillance and automated geofence/entry alerts to ensure child safety.

### 🚀 Key Highlights & Capabilities:
- **In-App Digital Game Wallet**: Instant balance recharge for game passes eliminating wait times at ticketing booths.
- **Live Video Feed Stream**: Secure live video streaming allowing parents to watch their children inside play areas.
- **Smart Entry/Exit Geofence Alerts**: Real-time push notifications delivered when a child enters or leaves specific attraction zones.
- **High-Performance Cross-Platform UI**: Built with Flutter for smooth rendering across iOS and Android platforms.

---

## 🛠️ Technical Stack | التقنيات المستخدمة
- **Mobile Framework**: Flutter (Dart)
- **Real-Time Backend Services**: Firebase Realtime Database & Cloud Messaging (FCM)
- **Live Video Integration**: RTSP / WebRTC Stream Integration
- **Payment & Wallet System**: Encrypted Payment Gateway API
