# 🚢 ALKASSAR Group Import & Export Corporate ERP
> **منصة مجموعة الكسار العالمية للاستيراد والتصدير والنظام الإداري للموارد البشرية**

---

## 📌 Arabic Overview | نظرة عامة
تطوير حل تقني شامل لمجموعة **الكسار للاستيراد والتصدير**، يدمج بين موقع تجاري تفاعلي يستعرض خدمات الشركة والشحنات الدولية، وبين لوحة تحكم إدارية متقدمة (Enterprise Dashboard) لتنظيم كافة العمليات التشغيلية والموارد البشرية.

### ✨ المميزات والخصائص الرئيسية:
- **نظام الموارد البشرية (Integrated HR Management)**: إدارة كشوف الموظفين، سجلات الحضور والانصراف، الإجازات، والرواتب.
- **نظام إدارة المحتوى (Custom CMS)**: تحكم كامل وبسيط في صفحات الموقع والمشاريع والشحنات المتاحة.
- **إدارة العمليات والتجارة**: متابعة ملفات الاستيراد والتصدير والوثائق الرسمية.
- **لوحة قيادة تفاعلية (Interactive Admin Dashboard)**: واجهة مرنة ومؤشرات أداء تساعد الإدارة على اتخاذ القرارات اليومية بسرعة ودقة.

---

## 🌐 English Overview
Engineered an all-in-one corporate digital portal and administrative ERP solution for **ALKASSAR Import & Export Group**. The platform couples a public-facing trade catalog showcasing global logistics capabilities with a feature-rich backoffice dashboard driving internal HR and operational efficiency.

### 🚀 Key Highlights & Capabilities:
- **Enterprise HR Sub-system**: Employee profile lifecycle, automated attendance tracking, leave request processing, and payroll workflows.
- **Dynamic Content Management (CMS)**: Fine-grained access control over corporate announcements, product catalogs, and services.
- **Logistics & Trade Management**: Real-time management of supply-chain files and trade documentation.
- **Executive Analytics Dashboard**: Modern interface featuring live metrics and operational telemetry.

---

## 🛠️ Technical Stack | التقنيات المستخدمة
- **Backend Core**: Laravel Framework
- **Admin System**: Livewire & Blade Components
- **Database**: MySQL with optimized indexing
- **UI/UX**: Custom Responsive CSS Architecture, Chart.js Visualizations
