# 📱 Rasidy Phone - Mobile Recharge & Digital Services Ecosystem
> **تطبيق رصيدي فون لشحن الرصيد والخدمات الرقمية مع لوحة تحكم متكاملة**

---

## 📌 Arabic Overview | نظرة عامة
تطوير منصة وتطبيق **رصيدي فون** المخصص للسوق اليمني، والذي يقدم خدمات شحن رصيد هواتف المحمول لمختلف شركات الاتصالات المحلية، بالإضافة إلى تداول وشراء الخدمات الرقمية وباقات الألعاب والاشتراكات عبر بنية رسمية آمنة عالية السرعة.

### ✨ المميزات والخصائص الرئيسية:
- **تطبيق موبايل سريع الاستجابة**: تطبيق Android سلس يمنح المستخدم إمكانية الوصول إلى خدمات الشحن الفوري والدفع 24/7.
- **إدارة شركات الاتصالات والشبكات**: دعم مرن لشبكات الاتصالات المتعددة وتحديث الباقات فورياً.
- **لوحة تحكم إدارية مركزية (Backoffice Dashboard)**: تحكم كامل في أسعار الخدمات، العروض، العمولات، وسجلات المشتركين.
- **تقارير مالية ومبيعات آنية**: متابعة حركة الأرباح اليومية، التحويلات الناجحة والمخفقة، وتحليلات المبيعات.
- **معمارية قابلة للتوسع**: تصميم النظام ليستوعب ملايين العمليات اليومية وإضافة خدمات رقمية جديدة بكل يسر.

## 🌐 English Overview
Engineered **Rasidy Phone**, a comprehensive fintech and mobile services distribution platform tailored for telecom recharge and digital vouchers. The platform combines a lightweight Android application with a Laravel-powered backend for real-time transaction processing.

### 🚀 Key Highlights & Capabilities:
- **Intuitive Android Mobile Interface**: Seamless mobile experience enabling users to recharge airtime and buy digital items instantantly.
- **Multi-Operator Support**: Dynamic integration supporting telecom operators with real-time balance checks and API top-ups.
- **Central Administrative Portal**: Complete operational toolset to manage service rates, commission structures, and user access.
- **Real-time Financial Telemetry**: In-depth transaction tracking, daily reconciliation logs, and sales performance dashboards.
- **Scalable Architecture**: Built for high concurrency to support expanding service catalogs and transaction volumes.

---

## 🛠️ Technical Stack | التقنيات المستخدمة
- **Mobile Frontend**: Flutter Framework (Dart)
- **Backend API & Core**: Laravel RESTful API Backend
- **Database Layer**: MySQL with ACID transaction guarantees
- **Security & Encryption**: JWT Auth, SHA256 Request Signing
